## 配置备份与换机迁移

Windows 和 Linux 共用终端菜单：**主菜单 → 配置备份 / 迁移**。

- **导出加密备份**：将配置保存为可跨机器传输的 `.nexus-backup` 文件；使用至少 12 个字符的独立密码，密码输入不回显，不覆盖已有文件，也不自动上传。
- **导入加密备份**：先校验和预览，默认取消；明确确认后替换完整配置，并为已有配置保存恢复副本。错误密码、损坏或不兼容文件、取消及写入失败均保留原配置。
- 使用 scrypt + AES-256-GCM 保护节点身份、私钥、证书及隧道凭据；当前支持备份格式 v1、配置 schema 2、NexusEdge 3.x。
- 发布附件新增 `MIGRATION.md`，并严格校验全部 10 个附件，全部上传成功后才公开 Release。

## 换机步骤与注意点

1. 在旧服务器导出，将备份文件安全传到新服务器，密码通过另一渠道传递；遗失密码无法恢复。
2. 新服务器运行 v3.1.0，先停止已有节点，再从迁移菜单导入。导入是完整替换，不合并节点；旧版明文 `config.json` 不能直接作为加密备份导入。
3. 导入后所有节点保持停用。旧公网 IP、机器专属监听地址、隧道覆盖地址及通知设置按迁移规则重置；域名、端口、节点身份与证书等保留，启用前检查 DNS、NAT、监听范围、证书、防火墙和云安全组。
4. 按需启用节点并启动；核心程序和系统自启需在目标机器单独准备。导入本身不会安装核心、启停服务或修改防火墙。

覆盖前保存的 `config.json.pre-import.*.bak` 是含凭据的**明文恢复副本**，仅留在受保护的数据目录，不作为跨机器传输文件。详细兼容范围、默认值、失败保护及恢复步骤见 [迁移文档](https://github.com/figozhu/nexus-edge/blob/v3.1.0/MIGRATION.md)。

## 下载

- Windows x64：`nexus-edge-windows-x64.exe`
- Linux x64：`nexus-edge-linux-x64`
- Linux arm64：`nexus-edge-linux-arm64`

三个程序均内嵌 Bun，无需单独安装 Bun；Linux 下载后需赋予执行权限。`SHA256SUMS` 覆盖全部 9 个有效载荷文件；其余附件包括可重构建源码、使用/迁移说明及许可证。

本次发布不更改运行服务器，也不自动部署或启动节点。
